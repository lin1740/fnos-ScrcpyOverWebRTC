# 穿云投屏（fnOS）— CloudPhone for fnOS

在飞牛 fnOS 上一键部署**穿云投屏**服务端：用浏览器就能远程查看与操控安卓设备，不用装多余的客户端。

本仓库是 [ScrcpyOverWebRTC](https://github.com/hqw700/ScrcpyOverWebRTC)（作者 hqw700）在飞牛 fnOS 上的**第三方非官方封装**，收录 FPK 打包脚本、容器编排、统一网关接入与安装/升级/运维脚本（对应源码目录：`cloudphone_all_<版本>`）。

## 一、应用性质

1. 本应用（appname = `cloudphone`，显示名「穿云投屏」）是开源项目 ScrcpyOverWebRTC（穿云投屏，<https://github.com/hqw700/ScrcpyOverWebRTC>，作者 hqw700）在飞牛 fnOS 上的**第三方非官方封装**，由社区开发者自行打包分发，与飞牛官方（广州铁刃智造技术有限公司）及上游项目作者均无任何隶属、授权或合作关系。
2. 本应用**只提供服务端**（信令 + TURN 中继 + Web 管理面板），**不含安卓模拟器、不含安卓系统镜像**，也**不修改上游任何代码**；被控端为使用者自己的安卓手机 / 平板 / 云机。
3. 应用本体**完全免费、开源、非商业**，不收取任何费用，不通过任何组件盈利。
4. 本应用**不捆绑任何上游软件本体**，仅在运行时通过 Docker 拉取上游公开镜像 `buutuu/scrcpy-over-webrtc`（按 digest 随包钉死已验证版本，避免上游更新 latest 导致行为漂移；主动切换用 `scripts/set_image.sh --upgrade`，跟随最新用 `--follow-latest`，回退用 `--pin <sha256:...>`）。该镜像内的信令服务端、Agent、Web 前端均由上游提供，其许可条款、更新节奏与功能边界以上游发布为准。
5. 上游提供的「授权设备数」等增值服务属于**上游作者的第三方付费授权**，费用由上游授权服务方直接收取，与飞牛官方及本应用发布者无关；**不付费不影响画面、终端、文件等全部基础功能**使用。
6. 一个安装包同时支持 x86_64 与 ARM64，按设备架构自动选择镜像，无需分开下载。

> 本应用通过飞牛统一网关访问（应用中心点开即为 `/app/cloudphone`，TLS 由网关终结），同时保留局域网直连端口（默认 `8443/TCP`，HTTPS 自签证书）。

### 2. 安装

- **方式一（推荐）**：飞牛应用中心搜索「穿云投屏」直接安装。
- **方式二**：手动安装 `cloudphone_all_x.y.z.fpk`（安装包随应用发布渠道提供；本仓库收录的是对应版本的源代码，可直接自行打包）。

安装要求与说明：

1. 系统版本 ≥ 1.1.8（`os_min_version`）；一个包同时适配 x86_64 / ARM64。
2. 首次安装需联网拉取镜像，取决于网速通常 **1~3 分钟**；建议在飞牛「Docker → 镜像仓库 → 设置 → 加速源设置」中配置可用加速源（本包拉取顺序：飞牛加速源 → DaoCloud → 1ms.run → Docker Hub 官方，前一个失败自动回退下一个）。
3. 安装向导可自定义端口；**只填想改的，不填的一律用默认值**，改一个端口不会影响其它端口。
4. 安装完成后容器自动拉起，约 **10~60 秒**可打开面板；初次拉镜像期间页面显示状态页属正常。

### 3. 访问与登录

- **应用中心入口（推荐）**：应用中心点击「打开」，经飞牛统一网关进入 `/app/cloudphone`，HTTPS 由网关终结，无需处理证书。
- **局域网直连**：`https://<NAS_IP>:8443`（默认 HTTPS，自签证书 CN=localhost，首次访问需在浏览器手动信任；建议替换 `/app/certs/server.crt|key` 为匹配域名的可信证书）。
- **默认账号**：`admin` / `admin123` —— **首次登录后请立即修改**；TURN 默认凭据（`cloudphone_user` / `cloudphone_secure_password`）建议一并修改。
- 改用自定义端口后，浏览器与 Agent 一律用新端口（如 `https://<NAS_IP>:9443`）；应用中心入口会自动跟随，个别情况未生效时在应用中心**停用后再启用一次**。

### 4. 端口说明

| 端口 | 协议 | 用途 |
| --- | --- | --- |
| 8443 | TCP | Web 面板 / 信令（HTTPS / WSS） |
| 3478 | TCP + UDP | TURN 服务 |
| 50000-50029 | UDP | 媒体中继（30 个端口） |

- 端口全部可在安装向导自定义，安装后可用 `bash <应用目录>/scripts/set_ports.sh` 查看 / 修改。
- **中继段由 Docker 逐个绑定**：段内只要有一个端口被宿主其它进程占用，整段映射就会失败、容器停在 Created 状态。安装时会自动预检并提示，按提示换段即可。
- **与「安卓模拟器」同时安装**：请把本应用改成 `9443 / 3479 / 51000-51100` 错开，否则会因端口占用无法启动。

### 5. 设备接入

面板「部署新设备」页提供三种方式（免 Root 一键部署、Magisk 模块、App 被控端），完整六种接入方式见上游文档：

- 网页端 WebUSB 部署（免驱免装 ADB，插线配对推送）
- 电脑 ADB 脚本一键部署（`agent-deploy.zip`）
- Magisk / KernelSU / APatch 模块（开机自启，`cpctl` 命令行运维）
- Android App 原生客户端（被控端支持 Root 或 Shizuku 免 Root 双模式）
- Docker / redroid 容器云手机（需映射指定 UDP 中继段）
- 自定义 ROM / Redroid 镜像内置 Agent（上游后续发布）

> **云手机容器场景注意**：容器内 Agent 的信令与 TURN 地址请使用宿主机在容器网桥中的可达地址，不要填 `127.0.0.1`；若在同一 fnOS 上使用「安卓模拟器」的 redroid 容器，请使用其注入的固定主机名 `host.docker.internal`（fnOS 会拦截 bridge 容器访问宿主局域网 IP）。

### 6. 数据与卸载

- 数据保存在数据卷 `cloudphone-webrtc-data`；卸载时**默认保留**，重装后账号与设备绑定仍在。
- 只有卸载向导中明确选择「同时删除数据」才会清除，操作不可逆，请先备份。

### 7. 外网访问

优先使用飞牛官方远程域名或内网穿透；确需端口映射时建议**只映射 TCP 8443 并使用 WebSocket 投屏**（WebRTC 的 UDP 媒体流对端口段要求较高）。请勿在无防护的情况下把端口直接暴露到公网。

### 8. 版本策略

版本号跟随上游：上游发布新版后，本应用重新打包并同步更新镜像 digest，随应用中心更新推送。已安装用户不受上游 `latest` 变动影响（镜像按 digest 钉死）；如需主动切换或回退，使用 `scripts/set_image.sh --upgrade` / `--pin <sha256:...>`。
